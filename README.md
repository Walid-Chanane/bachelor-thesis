# bachelor-thesis
Design and development of a web application for managing training sessions for new project promoters at NESDA.

## Abstract
The goal of our project is to design and develop a web application for managing training sessions for new project promoters at NESDA. To achieve this, we conducted a study of the current system through interviews with the different stakeholders and examined the documents used to get a clear understanding of the needs. After that, we used various UML diagrams to model and design our system, then moved on to setting up the database with SQL Server and developing the application with Java, HTML, CSS, and JavaScript, integrating frameworks like Spring Boot and Bootstrap.

Our solution meets all the users' needs and helps them get their tasks done efficiently.

**keywords:** promoter, project, wilaya agency, training session, NESDA.


## Résumé
Le but de notre projet est de concevoir et de réaliser une application web de gestion des sessions de formation des nouveaux promoteurs porteurs de projets chez NESDA. Pour cela, nous avons effectué une étude de l'existant à l'aide d'interviews avec les différents
acteurs du système, et étudiait les documents utilisés afin d'avoir une vue claire des besoins. Par la suite, nous avons utilisé différents diagrammes du langage UML pour modéliser et concevoir notre système pour ensuite passer à la mise en place de la base de données avec SQL
Server et au développement de l'application avec Java, HTML, CSS et JavaScript, en intégrant des frameworks tels que Spring Boot et Bootstrap.

Notre solution répond à tous les besoins des utilisateurs et les aide à accomplir leurs tâches de manière efficace.

**Mots clés :** promoteur, projet, agence de wilaya, session de formation, NESDA.
